# UX Specification

## Design principle
Premium architectural studio, not a generic corporate template.

## Navigation
Recommended:
- Home
- About
- Services
- Projects
- Process
- Contact
- Primary CTA: Book a Consultation

## Homepage sections
1. Hero
2. Brand/value proposition
3. Selected projects
4. Services
5. Why ZENKRAFT
6. Process
7. Testimonials/credentials, if verified
8. Consultation CTA
9. Contact/location
10. Footer

## Contact experience
The contact area shall provide three clear actions:
- Book a Consultation
- WhatsApp
- Call

The physical address and map should be visually prominent only after verification.

## Form UX
- Progressive disclosure where useful.
- Clear required/optional labels.
- Inline validation.
- Mobile-first.
- Preserve entered data after validation errors.
- Prevent duplicate submissions.
- Show loading and success/error states.

## Accessibility
Target WCAG 2.2 AA.
- Keyboard navigation.
- Visible focus states.
- Semantic headings.
- Accessible form labels.
- Sufficient contrast.
- Alt text for meaningful images.
- Reduced-motion support.

## Responsive breakpoints
Use implementation-specific breakpoints rather than tying UX requirements to one CSS framework.
Minimum validation widths:
- 320px
- 375px
- 768px
- 1024px
- 1440px
- 1920px
