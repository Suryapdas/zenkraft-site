# Change Control

## Requirement change procedure
1. Record the requested change.
2. Identify affected FR/AC/API/data/UX artifacts.
3. Update the source specification.
4. Update traceability.
5. Implement.
6. Run impacted acceptance tests.
7. Obtain business approval for externally visible changes.

## High-risk changes
Require explicit approval:
- Address
- Phone/WhatsApp
- Email
- Map pin
- Legal name
- Pricing/budget claims
- Testimonials
- Awards/certifications
- Privacy policy
- Data retention
