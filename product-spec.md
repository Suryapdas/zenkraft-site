# Product Specification

## 1. Product vision
Create a premium digital presence for ZENKRAFT Design Studios that converts website visitors into qualified project enquiries and consultation opportunities.

## 2. Business outcomes
- Increase qualified enquiries.
- Establish trust through portfolio and process transparency.
- Reduce friction between discovery and consultation.
- Capture structured project information.
- Give the client-engagement team a manageable lead pipeline.
- Make business/contact information authoritative and centrally configurable.

## 3. Primary user journeys

### Visitor → enquiry
Landing → Services/Portfolio → Trust signals → CTA → Project enquiry → Confirmation → Client-engagement follow-up.

### Visitor → direct contact
Landing/Contact → WhatsApp/Call/Email/Map → external communication.

### Lead → consultation
Enquiry received → qualification → status assignment → consultation scheduled → follow-up → conversion/lost.

### Admin → content
Admin login → Projects/Services/Leads → create/update/publish → audit trail.

## 4. Non-goals for MVP
- Online payment.
- Full construction ERP.
- Detailed project-management replacement.
- Public client financial information.
- Publishing unverified business details.

## 5. Success metrics
- Enquiry conversion rate.
- Qualified lead rate.
- Consultation booking rate.
- Lead response time.
- Lead-to-project conversion rate.
- Portfolio engagement.
- CTA click-through rate.
