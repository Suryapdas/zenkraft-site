# Content & Copy Specification

All publishable content must be editable without changing application source code.

## Required content blocks

### Hero
- Eyebrow
- Headline
- Supporting copy
- Primary CTA
- Secondary CTA
- Hero media

### About
- Studio story
- Philosophy
- Differentiators
- Credentials, only if verified

### Services
For each service:
- Name
- Short description
- Detailed description
- Deliverables
- Process
- CTA

### Projects
For each project:
- Project name
- Type
- Location
- Year
- Challenge
- Approach
- Outcome
- Gallery
- Scope

### Social proof
Testimonials, awards, certifications and client logos must be independently verified before publication.

## Editorial rule
Do not fabricate:
- Client names
- Project values
- Awards
- Certifications
- Years of experience
- Addresses
- Reviews/testimonials
